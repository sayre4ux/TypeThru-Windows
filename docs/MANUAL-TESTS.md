# 0.2.2 人手驗收清單

自動測試唔會發送真實按鍵、操作畫面或執行安裝／移除。以下由你喺本機同真實遠端環境驗證。
先喺空白 Notepad 測試，再試遠端；唔好用命令列或有重要未儲存資料嘅欄位做第一次測試。

## 開啟新版本

1. 喺舊 TypeThru 面板按 **Quit**。
2. 開啟專案嘅 `.build\review\0.2.2\TypeThru.exe`；呢個係獨立試用 build，版本應為 **0.2.2**。
3. 確認原有速度、快捷鍵同浮動 Type 按鈕 設定保留。唔需要重新安裝。

## 主面板同外觀

- 開面板，逐一試速度選單、Shift+Enter、五個測試按鈕、Settings 同 Quit；Diagnostics 喺 Settings。
- 選單展開同選項點擊時，面板唔應該提早消失；點面板外面就應該關閉。
- 開關面板後，原本遠端程式仍然係前景；唔應該因為面板或下拉選單搶走鍵盤焦點。
- 檢查淺色、深色、高對比模式，留意文字對比、停用狀態、焦點框同勾選狀態。
- 深色模式嘅開關標籤應該清楚可讀，下拉選單同箭嘴應該配合深色底；選完項目後唔應有方形色塊。
- 滑鼠同 Space 切換開關，確認視覺同儲存狀態一致；系統關閉動畫時，過場應即時完成。
- 喺 100%、150%、200% 縮放檢查文字同按鈕有冇截斷。雙螢幕不同 DPI 時移動 Settings，
  再喺另一螢幕開面板，兩者字體應該各自正確。
- 檢查工作列位於不同邊、第二螢幕同較矮顯示範圍；視窗同底部控制應可操作。
- 浮動 Type 按鈕：拖動、放開、重新啟動後位置保留；右鍵隱藏，再由 Settings 開返。
  拖動後返到原位再放開，或拖動時失去滑鼠捕捉，都唔應該誤觸打字。

## Settings

- 用 Tab／Shift+Tab、方向鍵、Space、Enter 操作控制，確認有可見焦點。
- 改快捷鍵、按 Esc 取消、按 Reset；錄製期間關閉 Settings，再試舊快捷鍵。
- 嘗試已被其他程式使用嘅快捷鍵：應解釋失敗，並保留先前可用設定。
- 切換方法、符號替換、Shift+Enter、浮動 Type 按鈕，重新開啟程式後應保留。
- 按 **Check Now**：顯示檢查中，重複按唔應產生並行檢查；斷網應顯示失敗。
- 開關自動更新選項；關閉後重新啟動，唔應進行自動檢查。
- Sign-in 係真實系統設定變更：你要驗證時先切換，確認 Windows 啟動項目同實際登入行為一致。
- 輸入／安裝更新進行期間，Quit 同移除設定唔應中斷工作。

## 真實打字及停止

1. 複製 `abcABC123 !@#`，本機 Caps Lock 關閉，喺 Notepad 用快捷鍵同面板各試一次。
2. 執行 Short、Capitals、Symbols、Smart symbols、Long 五個測試；確認大小寫、符號、Tab 同換行。
3. 複製尾部有 CRLF／多個換行嘅文字；尾部唔應多打一個 Enter。
4. Shift+Enter 開／關分別測試多行文字；喺聊天程式確認開啟時係換行，唔係送出。
5. Unicode 方法試中文、重音字母同 emoji；Scan code 方法遇到冇對應按鍵嘅字應整段拒絕。
6. 長文字輸入期間分別按 Esc、左／右／中／側滑鼠鍵、切換視窗，應停止；
   Shift+大寫輸入期間取消後，手動打一個小寫字，確認無殘留 Shift。
7. 喺測試倒數、快捷鍵放開後嘅等待、開始前點按 Esc，應取消而唔會之後繼續打字。
8. 快捷鍵觸發後立即轉去另一個程式，唔應將剪貼簿打入新視窗。
9. 開啟本機 Caps Lock 再用 Scan code，應提示關閉；輸入中按 Ctrl／Alt／Win／Caps Lock 應停止。
10. 換鍵盤配置，尤其有 dead key 嘅配置；本機同遠端配置保持一致，確認建立映射唔會污染下一個字。
11. Posted-window 只作診斷：Notepad 文字應保留大小寫；Shift+Enter 開啟時多行文字應拒絕。
12. 對住提升權限嘅目標程式測試時，普通權限 TypeThru 應提示限制，唔應自動要求提升權限。

## 真實遠端環境

- 視窗模式試快捷鍵；全螢幕鍵盤被攔截時使用浮動 **Type 按鈕**。
- 保留先前已驗證做法：唔好用 Ctrl+Alt 釋放鍵盤再打字，亦唔好加入修飾鍵「修復」序列。
- 五個速度分別檢查漏字／亂序；最快速度尤其要試編輯器同較重嘅應用程式。
- 重新驗證 Esc、點擊、焦點轉換停止，以及浮動 Type 按鈕 拖動唔會觸發打字。

## 發佈前更新／安裝

只喺你準備好測試帳戶／VM 時做；目前 build 未代表已完成以下測試。

- 用原有簽署金鑰建立較舊版到新版嘅正式簽署測試包。唔好重新產生更新金鑰。
- 舊版按 Install：新版啟動、設定保留、無額外權限提示；檢查版本同更新備份。
- 損壞 zip 或 signature：必須拒絕。有效舊版簽署 zip 冒認較新版：必須拒絕。
- 模擬下載失敗、安裝目錄不可寫、目標仍被鎖定：舊程式檔案應保留，錯誤應可理解。
- 檢查 zip、signature 同 installer 都喺 `.build\release`；安裝器只接受 x64-compatible 系統，
  使用每用戶安裝，最後再驗證卸載同 sign-in 項目清理。

有問題時請記低：build 版本、Windows 縮放／主題、使用方法／速度、實際步驟同結果。
Diagnostics 可以提供狀態，但唔需要貼含敏感資料嘅剪貼簿或遠端畫面。
